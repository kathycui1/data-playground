# Economic data

Automated **macro briefing pipeline** on World Bank annual GDP growth, CPI inflation, and unemployment (2000 onward).

Numbers come from code. A chat model is optional and only sees a typed **facts packet**, not the raw panel. Highlights whose figures do not match the packet are dropped.

```
World Bank API → parquet → facts packet → OLS + Ridge baseline → optional LLM → report.html
                                         ↘ FastAPI /facts /briefing /ask
```

## Setup

From the repo root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then set OPENAI_API_KEY if you want the briefing
```

`OPENAI_BASE_URL` defaults to OpenAI. Point it at Groq or any OpenAI-compatible gateway if you prefer.

## Run

```bash
# Fetch (or reuse cache), compute facts, optional briefing, write report.html
python experiments/economic-data/pipeline.py

# CI-style: committed sample parquet, no World Bank call, no model call
python experiments/economic-data/pipeline.py --fixture --skip-llm

# API (same packet; USE_FIXTURE=1 to skip a live fetch)
python experiments/economic-data/api.py
```

- `GET /health` `/facts` `/briefing`
- `POST /ask` `{"question": "…"}` — answers from the packet only
- `pytest` — transforms, grounding, fixture, API

Open `experiments/economic-data/report.html` in a browser (a local HTTP server avoids some browser restrictions on `file://`).

## What is computed vs generated

| Computed in Python | Generated by the model |
| --- | --- |
| Latest values, YoY, z-scores, flags | Executive summary and country notes |
| Pooled correlations and OLS | Risks and follow-up questions |
| Ridge inflation forecast vs last-value naive MAE | Highlights (values must match the packet) |

## Indicators

| Indicator | World Bank code |
| --- | --- |
| GDP growth (% annual) | `NY.GDP.MKTP.KD.ZG` |
| Inflation, CPI (% annual) | `FP.CPI.TOTL.ZG` |
| Unemployment (% of labor force) | `SL.UEM.TOTL.ZS` |

**World aggregate:** `WLD`  
**Comparison set:** United States, China, Germany, India, Brazil, Japan

`fetch_world_bank.py` writes `data/raw/world_bank_indicators.parquet` (gitignored).  
`fixtures/world_bank_sample.parquet` is a reduced copy for tests and CI.

## CI / GitHub Pages

`.github/workflows/ci.yml` runs pytest and a `--skip-llm` pipeline smoke test. It does **not** call OpenAI.

Commit the locally generated `report.html` (with briefing baked in) so other people can read the full result without an API key. `.env` is gitignored — do not add `OPENAI_API_KEY` as a GitHub Actions secret.

GitHub Pages is optional: on `main` CI copies the committed `report.html`. If Pages is not enabled, that job is allowed to fail; tests still gate the push. To publish: **Settings → Pages → GitHub Actions**.
